Claude Code 플러그인·Kiro 통합 포함. ③ **AWS Context** — 조직 데이터를 지식 그래프로 자동 매핑해 에이전트가 런타임에 거버넌스 데이터·비즈니스 규칙·도메인 지식에 접근 가능. Amazon Bedrock AgentCore에는 웹 기반 지식 접근·WAF Bot Control(AI 봇 유료화) 기능도 추가됐다.

### **[Google·개발 도구]** Gemini CLI 오늘(6/18)부터 서비스 종료 — Antigravity CLI로 전환 필수
- 6월 18일부터 Gemini CLI와 Gemini Code Assist IDE 확장이 Google AI Pro·Ultra 및 무료 사용자에 대해 요청 처리를 중단한다. 대체제는 Go로 재작성된 **Antigravity CLI(agy)** — 비동기 멀티에이전트 워크플로·백그라운드 세션·Antigravity 플러그인 아키텍처로 재설계됐다. 런칭 시점에 1:1 기능 동등성은 없으므로 자동화 스크립트 점검이 필요하다. Gemini Code Assist Standard/Enterprise 라이선스 조직은 영향 없음.
  - 💡 *Antigravity CLI(agy) = Gemini CLI를 대체하는 Google의 차세대 AI 코딩 에이전트 CLI. Go 재작성·비동기 멀티에이전트 지원*
  - 🔍 *Gemini CLI 기반 CI/CD 파이프라인이나 자동화 스크립트가 있다면 오늘 중으로 agy 마이그레이션 가이드를 확인하고 테스트해야 한다. 기업 라이선스 보유 조직은 예외.*
- 출처: [Google Developers Blog](https://developers.googleblog.com/an-important-update-transitioning-gemini-cli-to-antigravity-cli/) *(6/18 발행)*
