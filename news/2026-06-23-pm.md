## 🌐 AI 일반

### **[Google]** Gemini 2.5 Pro 'Deep Think' 추론 모드, AI Ultra 구독자 배포 시작
- Google이 Gemini 2.5 Pro의 추가 추론 모드 'Deep Think'를 6월 22일부터 Google AI Ultra($250/월) 구독자에게 순차 배포했다. 답변 전 복수 추론 경로를 병렬 탐색·자기 검증하는 방식으로, 과학·수학·일반 추론 벤치마크에서 현재 공개된 모델 중 최상위권 성능을 보인다. 소프트웨어 엔지니어링(SWE-bench)에서는 Fable 5, 창작·대화에서는 GPT-5.5가 앞서나 추론 집중 작업에서의 격차가 크게 좁혀졌다.
  - 💡 *Deep Think = 답변 생성 전 내부 추론 단계를 추가해 복잡한 문제를 병렬 탐색·검증하는 모드. OpenAI의 'Thinking', Anthropic의 'Extended Thinking'과 같은 기능 계열*
  - 🔍 *수학·과학·분석 작업에 Gemini를 활용한다면 AI Ultra 요금제 전환을 고려할 시점 — 단, 순차 배포 중이라 즉시 가용하지 않을 수 있으니 사전 확인 권장*
- 출처: [Google Blog](https://blog.google/products/gemini/gemini-2-5-deep-think/) *(6/22 발행)*

### **[OpenAI]** GPT-5.5-Cyber 정식 공개 + 'Patch the Planet' 오픈소스 보안 이니셔티브 출범
- OpenAI가 6월 22일 Daybreak 사이버 방어 프로그램을 확장해 방어 특화 모델 GPT-5.5-Cyber(CyberGym 점수 85.6%, 표준 GPT-5.5 대비 +3.8%p)를 정식 출시했다. Trail of Bits·HackerOne과 협력한 오픈소스 취약점 패치 프로그램 'Patch the Planet'도 함께 출범했으며, cURL·Go·Python·Sigstore 등 30개 이상의 오픈소스 프로젝트가 참여한다. Anthropic의 Project Glasswing에 대응하는 형태이며, 테스트에서 OpenBSD 커널 23년 된 버그, Chrome V8 취약점 5건, Safari WebKit 버그 10건 이상을 발굴했다.
  - 💡 *Daybreak = OpenAI의 사이버 방어 프로그램. GPT-5.5-Cyber(모델)·Codex Security(개발자 툴)·Patch the Planet(오픈소스 파트너십)이 이 우산 아래 운영됨*
  - 🔍 *오픈소스 프로젝트 메인테이너라면 Patch the Planet 파트너십 참여를 검토할 것 — AI가 취약점을 발굴하고 패치 PR까지 자동 생성하는 방식으로 운영*
- 출처: [SiliconAngle](https://siliconangle.com/2026/06/22/openai-expands-daybreak-patch-planet-full-gpt-5-5-cyber-release/) *(6/22 발행)*

### **[Claude]** Claude Fable 5, 오늘(6/23)부터 구독 포함 종료 — 사용 크레딧 별도 필요
- 6월 9일 출시 이후 Pro·Max·Team·Enterprise 구독 내 무료 제공되던 Claude Fable 5 접근이 6월 22일로 종료됐다. 오늘 6월 23일부터는 별도 사용 크레딧(입력 $10/백만 토큰·출력 $50/백만 토큰, Opus 4.8 대비 두 배)이 필요하며 Settings → Usage에서 사전 충전해야 한다. 모델 선택 창에는 계속 표시되지만 크레딧 없이는 작동하지 않는다. Anthropic은 캐파 여유가 생기면 구독 내 복원 예정이라 밝혔으나 시점은 미정이다.
  - 🔍 *Fable 5를 자동화 파이프라인이나 Claude Code에서 쓰는 경우 오늘 첫 실행 전 크레딧 충전 여부를 확인할 것 — 미충전 상태에서 에이전트가 돌아가면 예상치 못한 오류가 발생할 수 있음*

### **[OpenAI]** Codex Security, ChatGPT Pro·Enterprise·Business·Edu 전면 배포 — 다음 달까지 무료
- 3월 리서치 프리뷰로 시작한 OpenAI의 보안 특화 코딩 에이전트 Codex Security가 6월 22일부터 ChatGPT Pro·Enterprise·Business·Edu 구독자에게 Codex 웹을 통해 전면 배포됐으며, 배포 후 한 달간 무료다. 레포지토리 전체 맥락을 분석해 실제 공격 경로를 시뮬레이션·재현한 후 고신뢰도 취약점을 선별하고 패치 PR을 자동 생성한다. 3월 이후 3천만 커밋 스캔, 7만 개 이상 취약점 수정이 확인됐으며 GPT-5.5-Cyber 기반으로 업그레이드됐다.
  - 💡 *Codex Security = SAST(정적 코드 분석)와 달리 실제 공격 경로 재현까지 수행하는 AI 보안 에이전트 — false positive(오탐) 비율을 낮추는 것이 핵심 차별점*
  - 🔍 *ChatGPT 유료 구독자라면 이번 달 무료 기간에 실제 레포지토리를 먼저 스캔해볼 것 — 특히 오픈소스 의존성을 많이 사용하는 프로젝트에서 효과가 클 수 있음*
- 출처: [OpenAI](https://openai.com/index/gpt-5-5-with-trusted-access-for-cyber/) *(6/22 발행)*
