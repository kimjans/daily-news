### **[Microsoft]** Intelligent Terminal 출시 — Shell에 AI 에이전트 패널을 내장한 Windows Terminal 포크
- Build 2026에서 공개된 Windows Terminal 오픈소스 실험적 포크. Shell 안에 AI 에이전트 패널을 직접 통합해 명령 실패 시 오류를 자동 감지하고 컨텍스트 로드·수정 제안을 즉시 제공. GitHub Copilot CLI 기본 탑재, Claude Code·OpenAI Codex·Google Gemini 등 ACP 호환 에이전트 자동 감지 지원. Microsoft Store·winget 즉시 설치 가능하며 기존 Windows Terminal은 변경 없이 유지.
  - 💡 *ACP(Agent Client Protocol) = JetBrains·GitHub·Google 등이 채택한 에디터↔AI 에이전트 통신 오픈 표준. 설치된 ACP 호환 에이전트를 자동 감지해 연결하는 공통 인터페이스*
  - 🔍 *이미 Claude Code·Codex·Copilot CLI 중 하나를 쓰고 있다면 `winget install Microsoft.IntelligentTerminal` 한 줄로 Shell 내 AI 에이전트 패널을 즉시 활성화 가능 — 별도 IDE 없이 터미널 단에서 에러를 AI와 함께 처리할 수 있다.*
- 출처: [TechTimes](https://www.techtimes.com/articles/317761/20260604/microsoft-intelligent-terminal-ships-build-2026-ai-agent-fork-leaves-mainline-terminal-alone.htm) *(6/4)*
