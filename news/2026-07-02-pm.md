### **[Cloudflare·AI 크롤러]** Cloudflare, Content Independence Day 2.0 — AI 크롤 과금에서 인용 과금으로 전환
- Cloudflare가 7/1(제2회 Content Independence Day) AI 콘텐츠 수익화 정책을 개편했다. 기존 '크롤당 과금' 방식을 폐지하고, AI 답변에 콘텐츠가 실제로 인용될 때 출판사에 보상을 지급하는 **Pay Per Use** 모델로 전환했다. 1차 파트너는 Ceramic.ai·You.com이며, 9월 15일부터는 검색·훈련·에이전트 기능을 혼용하는 '복합 크롤러'가 광고 게재 페이지에서 기본 차단된다.
  - 💡 *Pay Per Use = 크롤 횟수가 아닌 AI 답변에서 실제로 인용된 횟수를 기준으로 출판사에 보상하는 콘텐츠 수익화 모델*
  - 🔍 *AI 서비스를 운영 중이라면 9/15 이전에 크롤러를 Search·Agent·Training 용도별로 반드시 분리해야 한다. 분리하지 않으면 광고 노출 페이지에서 기본 차단 대상이 된다.*

  - 🔍 *Meta가 클라우드 시장에 진입하면 AWS·Azure·GCP와의 경쟁으로 AI 추론 비용이 하락할 가능성이 있다. 당장의 행동 없이도 공급자 협상 레버리지에 영향을 줄 수 있으므로 관련 동향을 주시할 것.*
- 출처: [Bloomberg](https://www.bloomberg.com/news/articles/2026-07-01/meta-is-building-a-cloud-business-to-sell-excess-ai-compute) *(7/1 발행)*

## 💻 코딩 & 도구

### **[GitHub Copilot·Vision]** Copilot Vision 정식 출시(GA) — 이미지·PDF 첨부해 코드와 함께 분석
- GitHub Copilot Vision이 7/1 베타를 졸업하고 모든 유료 플랜에서 정식 제공된다. 이미지·PDF를 채팅 프롬프트에 직접 첨부하면 Copilot이 시각 콘텐츠를 코드 맥락과 함께 추론한다. 디자인 시안·스크린샷·에러 화면을 붙여 코드 수정을 요청하는 워크플로우가 바로 가능해진다.
  - 🔍 *UI 버그 스크린샷이나 Figma 디자인 PNG를 Copilot 채팅에 드래그앤드롭하면 텍스트 설명 없이도 코드 수정 요청이 된다. VS Code를 최신 버전으로 업데이트한 뒤 바로 시험해볼 것.*
- 출처: [GitHub Changelog](https://github.blog/changelog/2026-07-01-copilot-vision-is-generally-available/) *(7/1 발행)*

### **[GitHub Copilot·Kimi K2.7]** Kimi K2.7 Code, Copilot 모델 선택기 최초 오픈 웨이트 모델로 GA
- GitHub Copilot이 7/1 Kimi K2.7 Code를 정식 지원하며, Copilot 역사상 모델 선택기에 등장한 첫 오픈 웨이트 모델이 됐다. Moonshot AI(중국)의 코딩 특화 모델로 FrontierCode Extended 벤치마크에서 높은 점수를 기록했으며, Pro 플랜 이상에서 VS Code·Copilot CLI 등 주요 서피스에서 바로 선택 가능하다.
  - 💡 *Kimi K2.7 Code = Moonshot AI의 코딩 특화 오픈 웨이트 모델; 가중치가 공개되어 자체 배포가 가능하며 상업적 이용도 허용*
  - 🔍 *독점 모델 대신 오픈 웨이트 모델을 선호하거나 벤더 종속·비용이 고려 사항이라면 Copilot 설정 → 모델 선택에서 Kimi K2.7을 바로 전환해볼 수 있다.*
- 출처: [GitHub Changelog](https://github.blog/changelog/2026-07-01-kimi-k2-7-is-now-available-in-github-copilot/) *(7/1 발행)*

### **[GitHub Copilot·브라우저]** Copilot VS Code 브라우저 도구 GA — 에이전트가 라이브 앱 직접 탐색
- GitHub Copilot의 VS Code용 브라우저 도구가 7/1 정식 출시(GA)됐다. Copilot 에이전트가 실제 브라우저를 구동해 라이브 웹 앱을 탐색하고, 화면에서 발견한 정보를 채팅 컨텍스트로 직접 가져올 수 있다. Copilot CLI 자동 모델 선택 기능도 함께 GA됐으며, 작업 유형에 따라 최적 모델을 자동 라우팅한다.
  - 🔍 *로컬 dev 서버를 띄운 뒤 Copilot 에이전트에게 직접 페이지를 열어 확인하게 할 수 있다. 텍스트로 버그를 설명하는 대신 에이전트가 라이브 앱을 탐색하는 루프가 가능해졌다.*
- 출처: [GitHub Changelog](https://github.blog/changelog/2026-07-01-browser-tools-for-github-copilot-in-vs-code-are-generally-available/) *(7/1 발행)*
