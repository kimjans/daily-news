## 🌐 AI 일반

### **[OpenAI + AWS]** GPT-5.5·GPT-5.4·Codex, Amazon Bedrock 정식 출시 — AWS 계약 통합 청구
- OpenAI 최신 모델 GPT-5.5·GPT-5.4와 자율 코딩 에이전트 Codex, Bedrock Managed Agents가 Amazon Bedrock에서 GA. 기존 AWS IAM·VPC 거버넌스 체계 안에서 OpenAI 기능을 도입하고, 사용량을 기존 AWS 구매 약정(EDP)에 합산 가능.
  - 💡 *Amazon Bedrock = AWS 관리형 AI 서비스 플랫폼. Anthropic·Meta·Mistral 등 다수 모델을 단일 API와 AWS 보안 정책으로 호출할 수 있는 허브*
  - 🔍 *이미 AWS EDP 계약이 있는 기업이라면 별도 OpenAI 계약 없이 Bedrock 콘솔에서 바로 GPT-5.5와 Codex를 시범 적용 가능*

## 💻 코딩 & 도구

### **[OpenAI Codex on AWS]** 좌석 라이선스 없는 토큰 과금 — 엔터프라이즈 코딩 에이전트 진입 장벽 낮춤
- Bedrock에서 제공되는 Codex는 사용자당 좌석 라이선스 없이 순수 토큰 소비 기반으로 과금. Codex CLI·IDE 플러그인 모두 Bedrock 경로로 라우팅돼 PR 자동 생성·버그 수정·테스트 작성 워크플로를 기존 AWS 보안·컴플라이언스 체계 안에서 구동 가능.
  - 💡 *Codex = OpenAI의 자율 소프트웨어 개발 에이전트. 이슈 설명을 주면 코드 분석·수정·PR 생성까지 자율 처리*
  - 🔍 *보안 컴플라이언스로 외부 API 직접 사용이 막혀 있던 기업이라면, Bedrock 경로를 통해 사내 규정 안에서 Codex를 즉시 도입할 수 있게 됨*
