### **[Claude Mythos·Anthropic]** 미공개 Claude Mythos, 60시간 만에 양자내성 암호 HAWK 취약점 발견
- Anthropic의 미공개 모델 Claude Mythos Preview가 전문가 2년 검토로도 뚫지 못한 양자내성 암호 HAWK의 최선 공격을 자율적으로 개선하고, AES 7라운드 공격도 200~800배 빠른 새 기법(Möbius Bridge)을 도출했다. HAWK의 경우 최소 키 탈취 비용이 2^64→2^38 연산으로 절반 수준으로 줄었으며, 각 결과에는 약 $10만의 API 비용과 Anthropic 연구진 수백 시간의 검증이 소요됐다. Anthropic은 HAWK 개발자·NIST와 협력 공개했다.
  - 💡 *HAWK = NIST 양자내성 암호(PQC) 표준 후보 서명 알고리즘; PQC = 양자 컴퓨터로도 풀기 어렵도록 설계된 차세대 암호 표준*
  - 🔍 *HAWK·AES 기반 시스템을 운영 중이라면 NIST 업데이트 권고를 주시할 것. AI 자율 암호 분석 역량이 실증됐다는 점에서 보안 연구 방법론 변화가 빠르게 일어날 수 있다.*
- 출처: [CryptoTimes](https://www.cryptotimes.io/2026/07/29/anthropics-claude-ai-flags-new-cracks-in-two-major-crypto-algorithms/) *(7/29 발행)*

### **[FCC·미국 정책]** FCC, 중국산 신규 휴머노이드·사족보행 로봇 수입 즉시 금지
- 미국 FCC가 7/29 발표와 동시에 중국산 신규 휴머노이드·사족보행 로봇과 연결형 전력 인버터의 수입을 금지했다. 이미 출시·승인된 모델에는 소급 적용하지 않으며, 미출시 신규 모델에만 해당한다. 로봇의 데이터 수집·감시 기능과 인버터의 원격 제어·데이터 유출 위험이 국가안보 근거로 제시됐다. 현재 중국은 세계 휴머노이드 로봇 시장의 약 85%를 점유하고 있다.
  - 💡 *사족보행 로봇 = 네 발로 이동하는 로봇(Boston Dynamics Spot 유형); 전력 인버터 = 태양광·배터리·데이터센터에서 DC를 AC로 변환하는 장치, 원격 연결 기능이 취약점으로 지목*
  - 🔍 *AI 로봇 도입을 검토 중인 기업은 공급사의 국가를 즉시 확인해야 하며, 중국산 인버터를 데이터센터에 운용 중인 경우 FCC의 추가 고지에 대비해야 한다.*

- 출시 이래 최대 규모의 MCP 스펙 업데이트(2026-07-28)가 Agentic AI Foundation(AAIF) 주도로 공개됐다. 핵심 변화: ① 프로토콜 레이어 세션 완전 제거(무상태 구조, 어느 서버 인스턴스든 요청 처리 가능해 수평 확장이 일반 웹서비스 수준으로 단순화), ② OAuth 2.1 + OpenID Connect 기반 엔터프라이즈 인증 강화(Entra·Okta 연동, OAuth Mixup 공격 방어), ③ MCP Apps(샌드박스 UI)·Tasks(비동기 장시간 작업) 두 공식 확장 추가. Amazon Bedrock AgentCore에서 즉시 사용 가능하다. "18개월간의 교훈을 담은 원격 MCP 이후 가장 중요한 릴리스"(David Soria Parra, Anthropic).
  - 💡 *MCP(Model Context Protocol) = AI 모델이 외부 도구·데이터소스를 표준 방식으로 연결하는 오픈 프로토콜; AAIF(Agentic AI Foundation) = Linux Foundation 산하 MCP 관리 재단*
  - 🔍 *MCP 서버를 운영 중이라면 세션 핸들링 코드를 제거하고 헤더 기반 라우팅(MCP-Protocol-Version, Mcp-Method, Mcp-Name) 방식으로 전환이 필요하다. 공식 12개월 deprecation 정책도 함께 발표됐으므로 마이그레이션 일정을 미리 수립할 것.*
