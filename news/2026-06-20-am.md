## 💻 코딩 & 도구

### **[Claude Code]** Claude Code 2.1.183 — 자동 모드 파괴적 git 명령 자동 차단
- Anthropic이 6/19 Claude Code 2.1.183을 배포했다. 자동(auto) 모드에서 명시적 요청 없이 `git reset --hard`, `git checkout -- .`, `git clean -fd`, `git stash drop`, `git commit --amend`(에이전트가 해당 세션에서 만들지 않은 커밋), `terraform destroy` / `pulumi destroy` / `cdk destroy` 실행을 차단한다. deprecated 모델로 요청하거나 자동 업데이트될 때 경고가 출력되며, `attribution.sessionUrl` 설정으로 커밋·PR의 claude.ai 세션 링크를 생략할 수 있게 됐다. JetBrains IDE(IntelliJ·PyCharm·WebStorm 등) 터미널 깜빡임 버그도 수정됐다.
- 출처: [Claude Code Changelog](https://code.claude.com/docs/en/changelog) *(6/19 발행)*

### **[GitHub Copilot]** Copilot 사용 지표 API에 사용자별 일별 AI 크레딧 소비량 필드 추가
- GitHub이 6/19 Copilot 사용 지표 API에 `ai_credits_used` 필드를 추가했다. 기업·조직 레벨의 사용자 단위 리포트(users-1-day, users-28-day)에서 사용자별 일별 AI 크레딧 소비량을 조회할 수 있다. 사용량 기반 청구 API와 동일한 데이터 소스로, 팀별 비용 배분·예산 초과 모니터링에 활용할 수 있다.
  - 💡 *GitHub AI 크레딧 = 2026년 6월 도입된 Copilot 사용량 기반 청구 단위. 인라인 완성·에이전트 코딩 등 요청 유형마다 소비 크레딧이 다르게 책정됨*
- 출처: [GitHub Changelog](https://github.blog/changelog/2026-06-19-ai-credits-consumed-per-user-now-in-the-copilot-usage-metrics-api/) *(6/19 발행)*
