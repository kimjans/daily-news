## 💻 코딩 & 도구

### **[Claude Code·Alibaba]** 알리바바, 전 직원 Claude Code 사용 7/10부터 전면 금지 — 숨겨진 추적 코드 발견·대안은 자체 Qoder
- 알리바바가 7월 10일부터 전 직원의 Claude Code 사용을 금지하는 내부 지침을 발령했다. TechCrunch 보도에 따르면 Claude Code v2.1.91+(2026년 4월) 버전에 시스템 타임존 읽기·중국 기업명 키워드 대상 프롬프트 내 유니코드 삽입·날짜 형식 변경 등 코드가 내장돼 있었으며, 알리바바는 이를 '고위험 스파이웨어'로 분류했다. Anthropic은 해당 코드를 "실험"으로 인정하고 7월 1일 롤백했다고 밝혔다. 배경으로는 Anthropic이 알리바바(Qwen 팀)를 가짜 계정 2만5,000개로 Claude와 2,800만 회 상호작용해 모델 역량을 추출했다고 별도 고발한 사실도 있다. 직원들은 알리바바 자체 AI 코딩 어시스턴트 Qoder로 전환 중.
  - 💡 *Qoder = 알리바바 자체 개발 AI 코딩 어시스턴트*
  - 🔍 *Claude Code를 업무 환경에서 사용 중이라면 v2.1.91~롤백 이전 버전의 동작을 점검하고, 사내 AI 도구 승인 정책에 이 사례를 반영할지 검토할 것.*
- 출처: [TechCrunch](https://techcrunch.com/2026/07/04/alibaba-reportedly-bans-employees-from-using-claude-code/) *(7/4 발행)*
