### **[Cyera·Oasis Security·AI 보안]** AI 에이전트 보안 스타트업 $10억 인수 합병 — 비인간 신원 보안 시장 급성장
- 데이터 보안 유니콘 Cyera가 7/29 AI 에이전트 전용 비인간 신원(non-human identity) 보안 스타트업 Oasis Security를 약 $10억에 인수한다고 발표했다. 2022년 설립된 Oasis는 Accel·Craft Ventures·Cyberstarts 등으로부터 $1억9,500만을 유치했으며, AI 에이전트가 사용하는 계정의 접근 권한·감사 체계 관리에 특화돼 있다. 합병 후 두 회사는 어떤 에이전트가 어떤 데이터에 접근하는지 전체 가시성을 제공하는 통합 AI 보안 플랫폼을 구축할 계획이며, 에이전트 보안 분야 최대 딜로 꼽힌다.
  - 💡 *비인간 신원(non-human identity) = AI 에이전트·서비스 계정·봇이 시스템에 로그인할 때 사용하는 ID; Oasis Security = 이 에이전트 계정의 권한·접근 로그를 관리하는 보안 스타트업*
  - 🔍 *AI 에이전트를 내부 데이터베이스·SaaS에 연결하는 조직이라면 에이전트 계정의 최소 권한 원칙과 접근 감사 체계를 즉시 점검할 것. 에이전트 확산 속도 대비 권한 관리 도구가 부족한 경우가 많다.*

## 💻 코딩 & 도구

### **[GitHub Models·Azure]** GitHub Models 오늘(7/30) 완전 종료 — Azure AI Foundry로 즉시 이전 필요
- GitHub Models의 플레이그라운드·모델 카탈로그·추론 API·BYOK(Bring Your Own Key) 전체가 오늘(7/30) 완전히 종료됐다. 기존 고객 포함 모든 접근이 불가해지며, 마이그레이션 경로는 Microsoft Azure AI Foundry다. GitHub는 6/16 신규 고객 접근 중단, 7/16·7/23 두 차례 예고 brownout을 거쳐 오늘 최종 셧다운을 단행했다. GitHub Copilot은 계속 투자가 이루어지므로 모델 선택·코드 완성 기능은 유지된다.
  - 💡 *GitHub Models = GitHub에서 Llama·Phi 등 LLM을 저장소 내에서 바로 테스트할 수 있던 무료 모델 플레이그라운드·추론 API; BYOK = 외부 API 키를 가져와 GitHub Models를 통해 쓰는 방식*
  - 🔍 *GitHub Models API에 의존하는 CI 파이프라인·개발 환경이 있다면 오늘부터 오류가 발생한다. Azure AI Foundry(인증·비용 체계 변경) 또는 OpenRouter·Together AI 등 대체 API로 즉시 전환이 필요하다.*
- 출처: [GitHub Changelog](https://github.blog/changelog/2026-07-01-github-models-is-being-fully-retired-on-july-30-2026/) *(7/1 공지·7/30 효력 발생)*

### **[VS Code·에이전트 개발]** VS Code 1.131 출시 — 서브에이전트 실시간 상태 표시·내장 딕테이션 추가
- Visual Studio Code 1.131이 7/29 출시됐다. 핵심 변화: ① 서브에이전트 상태 패널 — 실행 중인 서브에이전트의 모델·경과 시간·활성 도구 호출을 대화창 열지 않고 한눈에 확인 가능, ② 내장 딕테이션(실험적) — Speech 확장 없이 채팅·에디터·터미널에서 음성 입력 지원, ③ 하이브리드 마크다운 에디터(실험적) — Agents 창에서 Markdown 파일 보기·수정·에이전트 실행 가능 주석 추가. 파이썬 환경 롤아웃도 이번 릴리스로 완료됐다.
  - 🔍 *병렬로 여러 에이전트를 돌리는 개발 환경에서는 서브에이전트 상태 패널이 즉시 유용하다. 1.131 업데이트 후 Agents 창 상단에서 각 에이전트 상태를 실시간으로 확인할 수 있다.*
