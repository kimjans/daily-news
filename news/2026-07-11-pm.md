## 💻 코딩 & 도구

### **[Cursor 3.11]** Cursor 3.11 — 메인 에이전트와 병행 실행되는 사이드 채팅 추가
- Cursor가 7월 10일 버전 3.11을 릴리즈했다. 핵심 신기능인 '사이드 채팅'은 `/side` 또는 `/btw` 명령어(또는 상단 + 버튼)로 메인 에이전트 대화를 중단하지 않고 별도 채팅을 병행 실행할 수 있다. 사이드 채팅은 메인 컨텍스트를 공유하는 독립적인 완전한 에이전트 대화로 동작하며, `@멘션`으로 결과를 메인 스레드에 가져올 수 있다. 이 외에도 에이전트 대화 전문 검색(이름·PR 번호 이상 내용 기반), 프로젝트·리포지토리 선택 UI도 개선됐다.
  - 🔍 *긴 리팩토링·코딩 세션 중 메인 에이전트를 멈추지 않고 사이드 채팅으로 대안 탐색·검증을 병행할 수 있어 워크플로우 인터럽트가 줄어든다.*
- 출처: [Cursor Changelog](https://cursor.com/changelog) *(7/10 발행)*

### **[Claude Code v2.1.207·Anthropic]** Claude Code v2.1.207 — Bedrock·Vertex·Foundry에서 Auto 모드 기본 활성화
- Anthropic이 7월 11일 Claude Code v2.1.207을 릴리즈했다. 주요 변경: ① Bedrock·Vertex AI·Foundry 환경에서 Auto 모드를 환경 변수(`CLAUDE_CODE_ENABLE_AUTO_MODE=1`) 없이 기본 제공(비활성화 시 settings의 `disableAutoMode` 사용); ② 긴 콘텐츠 출력 시 터미널 프리즈 수정; ③ auto-updater가 사용자 지정 런처 스크립트를 덮어쓰던 버그 수정.
  - 💡 *Auto 모드 = 퍼미션 프롬프트를 자동 판단해 안전한 작업은 중단 없이 실행, 위험 작업은 차단하는 Claude Code 기능*
  - 🔍 *Bedrock·Vertex·Foundry 기반 기업 배포 환경에서 별도 설정 없이 즉시 Auto 모드 사용 가능. `npm update -g @anthropic-ai/claude-code`로 업데이트.*
