- Moonshot AI가 6월 15일 Kimi K2.7-Code의 HighSpeed 변형을 공개했다. 중간 길이 코딩 입력 기준 약 180 tps, 짧은 컨텍스트 작업에서 최대 260 tps 처리 속도를 달성하며, 기존 K2.6 대비 추론 토큰 사용량 30% 절감을 유지한다. Kimi Code Beta 프로그램 멤버·Kimi API 개발자·Kimi Business 사용자 대상 순차 롤아웃 중이며, 용량 제약으로 초기에는 제한적 접근이다.
  - 💡 *Kimi K2.7-Code = Moonshot AI(중국 스타트업)의 1조 파라미터 MoE(전문가 혼합) 코딩 특화 오픈소스 모델 (Modified MIT 라이선스). MoE = 요청마다 일부 전문가 파라미터만 활성화하는 효율화 구조*

- 6월 16일, Microsoft Work IQ API가 정식 출시(GA)됐다. 에이전트가 이메일·캘린더·파일·채팅·협업 패턴 등 Microsoft 365 전 영역의 데이터와 도구에 접근할 수 있는 통합 API로, A2A(에이전트 간 통신)·원격 MCP 서버·REST API 3가지 통합 방식을 지원한다. 별도 구독 없이 Copilot Credits 소비형으로 청구되며, 경량 에이전트 인터랙션 기준 $0.20~$0.40/회 수준이다. Microsoft 365 Copilot 라이선스 없이도 독립 사용 가능하다.
