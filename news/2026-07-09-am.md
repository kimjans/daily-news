## 🌐 AI 일반

### **[Grok 4.5·xAI]** xAI, Grok 4.5 공개 — Cursor와 공동 학습·Opus 4.7급 성능·가격 60% 절감
- xAI가 Grok 4.5를 출시했다. Cursor와 코딩 데이터 공동 학습(xAI는 Cursor를 약 $60B에 인수)으로 Anthropic Opus 4.7급 코딩 성능을 확보했으며, 500K 토큰 컨텍스트 윈도우를 지원한다. 가격은 입력 $2·출력 $6/M 토큰으로 Opus 4.7($5/$25) 대비 약 60% 절감. Cursor 전 플랫폼(desktop·web·iOS·CLI·SDK)에서 사용 가능하나 EU 지역은 접근이 지연되고 있다.
  - 💡 *Grok = xAI의 LLM 시리즈; Grok 4.5는 Cursor와의 공동 학습으로 코딩에 특화된 버전*
  - 🔍 *코딩·에이전트 작업에 Opus 4.7급 성능이 필요하면서 비용을 낮추고 싶다면 Grok 4.5를 Cursor 내에서 즉시 테스트할 수 있다.*
- 출처: [TechCrunch](https://techcrunch.com/2026/07/08/) *(7/8 발행)*

### **[GPT-Live·OpenAI]** OpenAI, 실시간 전이중 음성 모델 GPT-Live 공개 — 동시 청취·발화·동시 통역 지원
- OpenAI가 전이중(full-duplex) 음성 대화 모델 GPT-Live를 출시했다. 사용자가 말하는 도중에도 AI가 동시에 응답하며 자연스러운 응답 신호("응", "맞아")와 실시간 동시 통역을 지원한다. GPT-Live-1(유료 플랜 기본)과 GPT-Live-1-mini(무료 기본) 두 티어로 제공되며, 복잡한 질의는 GPT-5.5 백엔드로 위임한다. API 개발자 접근은 추후 별도 신청 예정이다.
  - 💡 *전이중(full-duplex) = 송·수신이 동시에 이루어지는 통신 방식; 기존 push-to-talk 방식과 달리 AI와 사용자가 동시에 말할 수 있음*
  - 🔍 *실시간 음성 에이전트·통역 서비스를 구축 중이라면 GPT-Live API 대기자 신청을 미리 해두고 어제 출시된 gpt-realtime-2.1과 기능·가격을 비교해 선택할 것.*
- 출처: [TechCrunch](https://techcrunch.com/2026/07/08/) *(7/8 발행)*

### **[Claude ID·Anthropic]** Anthropic, 소비자 Claude에 신분증+셀피 생체 인증 시행 — 주요 AI 챗봇 중 첫 사례
- Anthropic이 일부 소비자 Claude(Free/Pro/Max) 계정을 대상으로 신원 인증을 의무화했다. 신원인증 스타트업 Persona를 통해 정부 발급 신분증 이미지·안면 영상·안면 기하학 템플릿을 수집하며, 수집 데이터는 Anthropic 서버가 아닌 Persona 서버에 저장된다. 일부 관할권에서는 수집 항목이 생체정보로 분류될 수 있다. API 키 사용자는 해당되지 않으며, 주요 AI 챗봇 중 생체 신원 인증을 소비자 약관에 명문화한 첫 사례다.
  - 💡 *Persona = 글로벌 KYC(Know Your Customer) 신원인증 서비스 스타트업; 안면 인식·신분증 스캔을 통한 비대면 본인 확인에 특화*
  - 🔍 *소비자 Claude 계정에 인증 요청이 뜨면 생체정보 수집 동의 전 Persona 개인정보 처리 방침을 반드시 확인할 것 — API 키 사용자는 이 요건과 무관하다.*
- 출처: [State of Surveillance](https://stateofsurveillance.org/july-8-2026/) *(7/8 발행)*

### **[Prime Intellect·시리즈A]** AI 컴퓨팅 스타트업 Prime Intellect, $130M 시리즈 A 조달 — 기업가치 $1B
- AI 에이전트 구축용 컴퓨팅 파워 및 소프트웨어 도구를 제공하는 스타트업 Prime Intellect가 Radical Ventures 주도로 $130M 시리즈 A를 완료했다(기업가치 $1B). NVIDIA Ventures·Intel Capital·Dell Technologies Capital·Iconiq이 참여했다. 분산 AI 컴퓨팅 레이어로, AI 에이전트 개발사가 GPU를 직접 확보하지 않고도 대규모 추론·학습 워크로드를 실행할 수 있도록 지원한다.
  - 💡 *분산 AI 컴퓨팅 레이어 = 여러 데이터센터·클라우드의 GPU를 단일 인터페이스로 묶어 제공하는 인프라 서비스*
  - 🔍 *자체 GPU 없이 에이전트 추론 워크로드를 스케일링해야 한다면 Prime Intellect 같은 분산 컴퓨팅 옵션이 직접 클라우드 예약 대비 비용·유연성 면에서 경쟁력이 있는지 검토할 것.*
- 출처: [TechCrunch](https://techcrunch.com/2026/07/08/) *(7/8 발행)*
