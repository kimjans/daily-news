## 🌐 AI 일반

### **[Kimi K3·Moonshot AI]** Moonshot AI, Kimi K3 오픈웨이트 공개 — 사상 최대 2.8T 파라미터 오픈소스 모델
- 중국 스타트업 Moonshot AI가 7/27 Kimi K3의 전체 가중치를 HuggingFace에 공개했다. 총 2.8조 파라미터(역대 최대 오픈웨이트)이지만 MoE 구조로 토큰당 약 104B만 활성화해 추론 효율을 유지한다. Modified MIT 라이선스로 자유롭게 다운로드·파인튜닝·배포 가능하며 1M 토큰 컨텍스트와 멀티모달 입력(텍스트·이미지·비디오)을 지원한다. Together AI·Modal이 Day-0 호스팅을 제공하며, OpenRouter·Cursor Router를 통해서도 즉시 접근 가능하다. 자체 배포에는 최소 H100 80GB × 8대가 필요하다.
  - 💡 *Kimi K3 = Moonshot AI의 최신 플래그십 LLM; MoE(Mixture-of-Experts) = 매 토큰마다 전체 파라미터 중 일부 전문가만 활성화해 연산 비용을 낮추는 구조*
  - 🔍 *오픈웨이트 공개로 중국 AI 모델의 데이터 주권 우려를 자체 호스팅으로 해소할 수 있게 됐다. 당장은 Together AI·OpenRouter 호스팅 접근이 현실적이며 MXFP4 기준 ~594GB 다운로드 필요.*

### **[Claude·Anthropic·개인정보]** Claude 공유 채팅, Google에 수백 건 인덱싱 — API 키·임상 기록 노출
- 7/27 Reddit에서 `site:claude.ai/share` 검색으로 수백 건의 Claude 공유 채팅·Artifact가 Google에 공개 노출됨이 알려졌다. 노출 내용에는 임상시험 기록, API 키, 신용카드 정보, 미성년자 이름과 연락처 등이 포함됐다. Anthropic은 "공유 기능은 의도된 설계"라며 `noindex` 기본 설정 적용을 거부했다. 개발자 커뮤니티는 공유 기능의 기본값이 크롤링을 허용하는 방식임을 비판하고 있다.
  - 💡 *`noindex` = 검색 엔진에 해당 페이지를 색인하지 말도록 요청하는 HTML 메타 태그*
  - 🔍 *Claude 공유 링크를 외부 포럼·SNS에 올린 적 있다면 `site:claude.ai/share [키워드]`로 즉시 노출 여부 확인할 것. 민감 정보가 포함된 링크는 Claude 설정에서 즉시 비활성화해야 한다.*

- Kimi K3가 Arena.ai의 Frontend Code Arena 리더보드에서 Claude Fable 5(1,631점)·GPT-5.6 Sol(1,618점)을 제치고 1위(1,679점)를 기록 중이다. 7/27 오픈웨이트 공개로 개발자는 API 의존 없이 이 모델을 직접 인프라에서 실행할 수 있다. OpenRouter·Cursor Router·Fireworks AI를 통해 Day-0부터 호스팅 접근이 가능하며, Moonshot의 공식 Kimi Code CLI(MIT 라이선스, TypeScript)와 연동된다. 다만 llama.cpp·Ollama·LM Studio는 Kimi Delta Attention을 아직 지원하지 않아 순수 로컬 배포는 연말 이후가 현실적이다.
  - 💡 *Frontend Code Arena = Arena.ai의 프론트엔드 코드 생성 전문 블라인드 평가 리더보드; Kimi Code CLI = Moonshot AI가 제공하는 오픈소스 터미널 코딩 에이전트*
  - 🔍 *Cursor Router나 OpenRouter에서 K3를 선택하면 즉시 프론트엔드 코딩 1위 모델을 사용할 수 있다. 데이터 프라이버시가 민감한 팀은 연말에 llama.cpp 지원이 추가되는 시점에 셀프 호스팅을 검토할 것.*
